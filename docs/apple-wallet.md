# Apple Wallet لتذاكر نيون

## الحالة

تم تجهيز إنشاء ملف `.pkpass` موقّع لكل تذكرة، بنفس رمز الدخول المستخدم في نيون.
يبقى خيار المحفظة معطلاً مع توضيح السبب إذا لم تُضبط الشهادات الصحيحة.
لا تتطلب الميزة ترحيلاً لقاعدة البيانات.

## إعداد Apple

1. من حساب Apple Developer الخاص بالمؤسسة، أنشئ Pass Type ID مثل `pass.org.neonedu.events`.
2. أنشئ شهادة Pass Type ID له باستخدام CSR، واحتفظ بالمفتاح الخاص المقابل لها.
3. صدّر الشهادة والمفتاح بصيغة PEM. جهّز شهادة Apple WWDR الوسيطة الصحيحة التي وقّعت شهادة التذكرة.
4. أضف المتغيرات التالية إلى بيئة السيرفر المحلية والإنتاجية ثم أعد التشغيل:

| المتغير | القيمة |
| --- | --- |
| `APPLE_WALLET_PASS_TYPE_ID` | معرّف التذكرة الصادر من Apple |
| `APPLE_WALLET_TEAM_ID` | معرّف فريق Apple Developer |
| `APPLE_WALLET_SIGNER_CERT_BASE64` | محتوى شهادة PEM مشفراً بـ Base64 |
| `APPLE_WALLET_SIGNER_KEY_BASE64` | محتوى المفتاح الخاص PEM مشفراً بـ Base64 |
| `APPLE_WALLET_WWDR_CERT_BASE64` | محتوى شهادة WWDR بصيغة PEM مشفراً بـ Base64 |
| `APPLE_WALLET_SIGNER_KEY_PASSPHRASE` | كلمة مرور المفتاح إذا كان مشفراً |

لا تستخدم `NEXT_PUBLIC_` لهذه القيم، ولا ترفع المفاتيح والشهادات الخاصة إلى GitHub.
يتحقق السيرفر من تاريخ صلاحية الشهادات، وتطابق الفريق والمعرّف والمفتاح الخاص والجهة الموقّعة.

## الاستخدام والحماية

- افتح صفحة التذكرة بحساب المشتري واضغط «إضافة إلى Apple Wallet».
- افتح الملف على iPhone وأكد الإضافة داخل Wallet. الحفظ من كمبيوتر لا يعني الإضافة تلقائياً إلى الهاتف.
- مسار التنزيل `/api/tickets/[ticketId]/wallet` يتطلب تسجيل الدخول وملكية تذكرة لطلب مدفوع وحساب نشط.
- لا يمكن إصدار ملف لتذكرة ملغاة أو مستخدمة أو انتهت فعاليتها.
- الملف خاص بالمستخدم ويُرسل دون تخزين مؤقت. لا يحتوي البريد أو اسم المشتري.
- يستخدم الرمز نفسه، لذلك المسح يظل خاضعاً لفحص حالة الطلب والتذكرة في نيون ومنع إعادة الدخول.
- هذه النسخة ثابتة: لا تشمل تحديثات Wallet عبر push أو تسجيل الأجهزة. إلغاء التذكرة أو استخدامها يمنع الدخول من السيرفر، لكنه لا يحدّث مظهر نسخة Wallet المحفوظة تلقائياً.
- عند تغيير `EVENT_TICKET_SECRET` تتعطل الرموز الصادرة سابقاً، بما فيها ملفات Wallet.

## التحقق

```powershell
pnpm exec tsx --test scripts/test-apple-wallet.ts scripts/test-wallet-route.ts scripts/test-event-tickets.ts
```

الاختبارات تنشئ شهادة اختبار محلية للتحقق من التوقيع وبنية الملف، وليست شهادة تقبلها Apple.
بعد ضبط الشهادات الحقيقية، يجب اختبار الإضافة على iPhone والمسح عند الدخول والإلغاء.
